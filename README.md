# 桜町 · 春日鉄道

全新制作的 Three.js 日式樱花铁路微缩场景。未使用或修改任何旧工程，也不依赖远程模型、图片、字体或 CDN。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
```

```bash
npm run dev
```

打开 http://localhost:5178 。默认只显示三维场景，没有工具栏、文字覆盖层或人物。鼠标左键或右键拖动旋转，滚轮缩放；触屏单指旋转，双指缩放并旋转。

## 构建与验证

```bash
npm run build
```

```bash
npm test
```

开发服务启动后，可用本机 Chrome 执行浏览器检查及截图：

```bash
node scripts/verify-browser.mjs
```

截图和浏览器验证结果存放在 `verification/`。正式发布文件位于 `dist/`，通过任意静态 HTTP 服务即可托管。

## 场景

- 完整方形切片底座、两端拱形隧道、单线轨道与道床。
- 乡间无人站、日式站名牌、候车棚、长椅、时刻表、售票设备和自行车停放处。
- 两节地方电车，粉色和青绿色腰线，双面车窗、驾驶室、空调、受电弓、转向架和车轮。
- 黑黄警示杆、红白遮断杆、交替红灯、铁路信号灯、架空电线和接触网。
- 樱花树、持续飘落花瓣、住宅、菜地和花坛。
- 约 40 度默认正交俯视，完整支持环绕观察和缩放，适配手机竖屏。

## 文件

- `src/model.js`：公共几何、材质与站牌绘制。
- `src/landscape.js`：底座、隧道、樱花和自然环境。
- `src/station.js`：站台、站房、住宅及生活设施。
- `src/infrastructure.js`：铁路、道口、信号与架空电线。
- `src/train.js`：列车模型。
- `src/motion.js`：独立、可测试的列车及道口时序。
- `src/main.js`：场景组装、灯光、镜头和渲染。

开发模式提供 `window.__diorama` 调试入口，可冻结时间、切换视角和检查渲染状态；生产构建不暴露该入口。
